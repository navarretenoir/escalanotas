# Escala de Notas

Hecha para el **cálculo de notas escolares en Chile** (1,0 a 7,0): genera la escala con cualquier exigencia y puntaje, responde qué nota
es un puntaje y cuántos puntos pide una nota, y calcula las notas de un curso completo con promedio, mediana, aprobación y distribución.
Exporta a PDF, Excel, Word, CSV e imagen, sin internet. Modo claro (cuaderno cuadriculado) y oscuro (pizarra).

## English

**Grading Scale** is made for calculating school grades in Chile (1.0–7.0): it builds the scale for any passing threshold and maximum
score, tells which grade a score gets and how many points a grade needs, and computes a whole class with average, median, pass rate and
distribution. Exports to PDF, Excel, Word, CSV and image, offline. Light (grid notebook) and dark (chalkboard) themes.

**Developed by Javiera Navarrete** · License GPL-3.0-or-later. The interface is in Spanish (Chile).
